# FleckSimon.com — Personal Profile

This repository contains a single static personal profile page for Simon Fleck: Profile, Work, Projects, Contact.

## Architecture

- Static website built with semantic HTML and responsive CSS.
- One page: `index.html`, served at `/`.
- Section structure: hero, profile statement, work (domains), projects, milestones, contact.
- No JavaScript required.

## Hosting

This site is designed for GitHub Pages.

### Option 1: GitHub Pages from `main`
1. Create a GitHub repository from this folder.
2. Go to repository Settings > Pages.
3. Set source to `main` branch and folder `/root`.
4. Visit `https://<username>.github.io/<repo>/`.

### Option 2: Custom domain
- Use the same folder structure and configure custom domain in GitHub Pages settings.
- The site will be available at `https://flecksimon.com/` if the domain is mapped and DNS is configured.

## Files

- `index.html`: the profile page.
- `profile.css`: styling and layout.
